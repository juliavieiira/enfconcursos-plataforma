# 📚 Questões e Provas de Língua Portuguesa

Esta pasta é reservada exclusivamente para os cadernos de provas e questões de **Língua Portuguesa** (SELECON, IBAM, VUNESP, etc.).

---

### 📤 Como adicionar seus arquivos aqui:
1. No GitHub, clique em **`Add file` ➔ `Upload files`**
2. Arraste todos os seus PDFs de Português aqui para dentro.
3. Clique em **`Commit changes`**.
4. O sistema irá extrair, criar os códigos **`LP0001`**, **`LP0002`**..., gerar gabaritos comentados com a regra gramatical e análise de distratores, e disponibilizar na plataforma!
